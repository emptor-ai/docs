## Self review

Before handing off any PR for human review, read and complete
[`docs/self-review.md`](docs/self-review.md). Review the entire PR diff with
Ponytail, resolve findings, run the appropriate checks, and record the results
under **Self review** in the PR description. Repeat after changes. Keep the PR
draft until complete; do not request or re-request a teammate's review early.
