# Översikt över leverantörsguider

> Uppgiftsorienterade guider för att integrera med OpenWrench Supplier API

[Referensen för Supplier API](/supplier-api/introduction) dokumenterar varje slutpunkt för sig. Dessa guider täcker de arbetsflöden som spänner över flera slutpunkter, det du faktiskt bygger.

## Var du börjar

- Ny med API:et? Börja med [Snabbstart](/supplier-guides/quickstart) för att göra din första autentiserade förfrågan.
- Integrerar du ett specifikt flöde? Hoppa till den matchande how-to i sidofältet.
- Behöver du konceptuell bakgrund? Se [Grundläggande begrepp](/supplier-guides/concepts) för hur arbetsordrar, servicebesök, offerter och fakturor hänger ihop.

## Vad som finns här

- **Kom igång**: snabbstart och autentisering.
- **Begrepp**: datamodellen på leverantörssidan.
- **How-to:s**: acceptera en arbetsorder, schemalägga och dokumentera ett servicebesök, skicka in offerter och fakturor, hämta teknikertid från WrenchMode.
- **Drift**: hastighetsgränser, felhantering och versionering.
