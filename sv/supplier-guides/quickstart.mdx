# Snabbstart

> Gör din första autentiserade förfrågan mot Supplier API på under fem minuter

## Förutsättningar

- En Supplier API-nyckel och en delad hemlighet från OpenWrench. Begär dem från [support@useopenwrench.com](mailto:support@useopenwrench.com).
- Ett skal med `curl`, eller vilken HTTP-klient som helst.

## 1. Verifiera dina uppgifter

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/ping"
```

Ett `200`-svar bekräftar att båda rubrikerna är giltiga. En `401` betyder att en av dem saknas eller är fel.

## 2. Lista inkommande arbetsordrar

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/work_orders?limit=5"
```

Svaret följer standardhöljet: `type`, `data` (en array), `count` och `status`.
