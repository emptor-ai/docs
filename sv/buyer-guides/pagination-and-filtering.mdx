# Paginering och filtrering

> Bläddra genom stora resultatuppsättningar och begränsa dem med fältfilter

List-slutpunkter accepterar fyra standardfrågeparametrar:

- `offset`: antal poster att hoppa över (standard `0`).
- `limit`: sidstorlek (standard `10`, max `25`).
- `sort_by`: fältnamn att sortera på.
- `order`: `asc` eller `desc`.

Varje ytterligare frågeparameter behandlas som ett **fältfilter**: skicka fältnamnet med ett värde, eller en kommaseparerad lista av värden, för att begränsa resultatuppsättningen. Varje slutpunkts referenssida listar dess viktigaste filter.

## Paginera en fullständig resultatuppsättning

Loopa tills du har hämtat `count` poster:

```bash theme={null}
# Page 1
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/work_orders?limit=25&offset=0"

# Page 2
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/work_orders?limit=25&offset=25"
```

Värdet `count` i svarshöljet är totalen, inte antalet på den här sidan.

## Filtrering

Filtrera på valfritt dokumenterat fält. Separera värden med komma för att matcha vilket som helst av dem:

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/work_orders?status=open,in_progress&limit=25"
```

## Sortering

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/work_orders?sort_by=created_at&order=desc"
```

## Hastighetsgränser och paginering

Pagineringsloopar kan slå i hastighetsgränsen (10 förfrågningar per 20-sekundersfönster per nyckel). Sov mellan sidorna, eller fånga `429`-svar och backa av. Se [Fel och hastighetsgränser](/buyer-guides/errors-and-rate-limits).
