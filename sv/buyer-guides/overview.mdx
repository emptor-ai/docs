# Översikt över köparguider

> Uppgiftsorienterade guider för att integrera med OpenWrench Buyer API

[Referensen för Buyer API](/buyer-api/introduction) dokumenterar varje slutpunkt för sig. Dessa guider täcker de arbetsflöden som spänner över flera slutpunkter, det du faktiskt bygger.

## Var du börjar

- Ny med API:et? Börja med [Snabbstart](/buyer-guides/quickstart) för att göra din första autentiserade förfrågan.
- Integrerar du ett specifikt flöde? Hoppa till den how-to som matchar ditt användningsfall i sidofältet.
- Behöver du konceptuell bakgrund? Se [Grundläggande begrepp](/buyer-guides/concepts) för hur arbetsordrar, tillgångar, platser och leverantörer hänger ihop.

## Vad som finns här

- **Kom igång**: snabbstart, autentisering och en rundtur i svarshöljet.
- **Begrepp**: datamodellen och hur delarna passar ihop.
- **How-to:s**: recept från början till slut: skapa och skicka ut arbetsordrar, paginera stora resultatuppsättningar, hantera återförsök av webhooks, stämma av fakturor.
- **Drift**: hastighetsgränser, felhantering och versionering.
