# Démarrage rapide

> Effectuez votre première requête authentifiée à l'API Fournisseur en moins de cinq minutes

## Prérequis

- Une clé d'API Fournisseur et un secret partagé OpenWrench. Demandez-les à [support@useopenwrench.com](mailto:support@useopenwrench.com).
- Un terminal avec `curl`, ou tout autre client HTTP.

## 1. Vérifier vos identifiants

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/ping"
```

Une réponse `200` confirme que les deux en-têtes sont valides. Une réponse `401` signifie que l'un d'eux est manquant ou erroné.

## 2. Lister les bons de travail entrants

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/work_order/work_orders?limit=5"
```

La réponse suit l'enveloppe standard : `type`, `data` (un tableau), `count` et `status`.
