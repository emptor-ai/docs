# Crear y despachar una orden de trabajo

> Flujo completo para convertir una necesidad de mantenimiento en una orden de trabajo asignada

<Info>
  Esta guía es una plantilla. Completa las llamadas exactas a los endpoints y los payloads para tu integración.
</Info>

## Requisitos previos

- Una clave de la Buyer API (consulta [Autenticación](/buyer-guides/authentication)).
- Una ubicación conocida y, opcionalmente, uno o más activos que asociar.
- Un proveedor de tu red (o los criterios para elegir uno).

## 1. Confirma la ubicación y el activo

Recupera la ubicación y los activos que planeas asociar para tener sus ids y estado actual.

## 2. Crea la orden de trabajo

Envía la orden de trabajo con su ubicación, activos, oficio y descripción. Anota el id de la orden de trabajo devuelta.

## 3. Asigna un proveedor

Despacha la orden de trabajo a un proveedor de tu red.

## 4. Rastrea el estado

Consulta la orden de trabajo (o recibe webhooks, si están configurados) a medida que el proveedor acepta, programa y completa el trabajo.

## 5. Revisa la cotización y la factura

Aprueba cualquier cotización enviada y luego concilia la factura final con los cargos esperados.
