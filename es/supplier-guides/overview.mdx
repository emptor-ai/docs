# Descripción general de las guías para proveedores

> Guías orientadas a tareas para integrar con la Supplier API de OpenWrench

La [referencia de la Supplier API](/supplier-api/introduction) documenta cada endpoint uno por uno. Estas guías cubren los flujos de trabajo que abarcan varios endpoints, es decir, lo que realmente construyes.

## Por dónde empezar

- ¿Nuevo en la API? Empieza con la [Guía rápida](/supplier-guides/quickstart) para hacer tu primera solicitud autenticada.
- ¿Integras un flujo específico? Ve directamente a la guía práctica correspondiente en la barra lateral.
- ¿Necesitas contexto conceptual? Consulta [Conceptos básicos](/supplier-guides/concepts) para entender cómo se relacionan las órdenes de trabajo, las visitas de servicio, las cotizaciones y las facturas.

## Qué encontrarás aquí

- **Primeros pasos**: guía rápida y autenticación.
- **Conceptos**: el modelo de datos del lado del proveedor.
- **Guías prácticas**: aceptar una orden de trabajo, programar y documentar una visita de servicio, enviar cotizaciones y facturas, y obtener el tiempo de técnicos de WrenchMode.
- **Operaciones**: límites de tasa, gestión de errores y versionado.
