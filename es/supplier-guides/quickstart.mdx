# Guía rápida

> Haz tu primera solicitud autenticada a la Supplier API en menos de cinco minutos

## Requisitos previos

- Una clave de la Supplier API y un secreto compartido de OpenWrench. Solicítalos a [support@useopenwrench.com](mailto:support@useopenwrench.com).
- Una shell con `curl`, o cualquier cliente HTTP.

## 1. Verifica tus credenciales

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/ping"
```

Una respuesta `200` confirma que ambas cabeceras son válidas. Un `401` significa que falta una o es incorrecta.

## 2. Lista las órdenes de trabajo entrantes

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/work_orders?limit=5"
```

La respuesta sigue la envoltura estándar: `type`, `data` (un array), `count` y `status`.
