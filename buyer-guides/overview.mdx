The [Buyer API reference](/buyer-api/introduction) documents every endpoint one at a time. These guides cover the workflows that span multiple endpoints — the things you actually build.

## Where to start

- New to the API? Start with the [Quickstart](/buyer-guides/quickstart) to make your first authenticated request.
- Integrating a specific flow? Jump to the how-to that matches your use case in the sidebar.
- Need conceptual background? See [Core concepts](/buyer-guides/concepts) for how work orders, assets, locations, and suppliers relate.

## What's here

- **Getting started** — quickstart, authentication, and a tour of the response envelope.
- **Concepts** — the data model and how the pieces fit together.
- **How-tos** — end-to-end recipes: creating and dispatching work orders, paginating large result sets, handling webhook retries, reconciling invoices.
- **Operations** — rate limits, error handling, and versioning.
