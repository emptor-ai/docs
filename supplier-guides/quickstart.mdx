## Prerequisites

- A Supplier API key and OpenWrench shared secret. Request them from [support@useopenwrench.com](mailto:support@useopenwrench.com).
- A shell with `curl`, or any HTTP client.

## 1. Verify your credentials

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/ping"
```

A `200` response confirms both headers are valid. A `401` means one is missing or wrong.

## 2. List incoming work orders

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/work_orders?limit=5"
```

The response follows the standard envelope: `type`, `data` (an array), `count`, and `status`.
