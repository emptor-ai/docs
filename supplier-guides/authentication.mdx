# Authentication

> Header requirements, scoping, and key handling for the Supplier API

Every Supplier API request must carry two headers:

- `X-API-KEY` — your Supplier API key, issued per supplier contact.
- `OW-KEY` — the OpenWrench shared secret issued alongside the key.

Requests missing either header return `401`.

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/supplier/ping"
```

## Scoping

Your key is scoped to a single supplier contact, which resolves to one facility. Every list endpoint filters results to that scope automatically. You only ever see work orders, service calls, quotes, and invoices that belong to your facility.

## Key rotation

Request a new key/shared-secret pair from [support@useopenwrench.com](mailto:support@useopenwrench.com), deploy the new pair, then ask support to revoke the old one. Keys do not expire on their own.
