# Démarrage rapide

> Effectuez votre première requête authentifiée à l'API Acheteur en moins de cinq minutes

## Prérequis

- Une clé d'API Acheteur et un secret partagé OpenWrench. Demandez-les à [support@useopenwrench.com](mailto:support@useopenwrench.com).
- Un terminal avec `curl`, ou tout autre client HTTP.

## 1. Vérifier vos identifiants

Appelez `GET /v1/buyer/ping` pour confirmer que votre clé et votre secret partagé fonctionnent :

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/ping"
```

Une réponse `200` confirme que les deux en-têtes sont valides. Une réponse `401` signifie que l'un d'eux est manquant ou erroné.

## 2. Inspecter l'identité associée à votre clé

`GET /v1/buyer/me` retourne le contact, l'établissement et l'entreprise auxquels votre clé est associée. Chaque endpoint de liste filtre automatiquement selon cette portée.

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/me"
```

## 3. Lister vos premiers bons de travail

```bash theme={null}
curl -H "X-API-KEY: <your-key>" -H "OW-KEY: <shared-secret>" \
  "https://api.useopenwrench.com/api/external/v1/buyer/work_orders?limit=5"
```

La réponse suit l'enveloppe standard : `type`, `data` (un tableau), `count` et `status`.
